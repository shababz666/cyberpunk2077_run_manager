HOW TO USE THIS

WHAT THIS IS

A planning and tracking tool for a single Cyberpunk 2077 playthrough. You mirror your real decisions here as you make them, and it tells you what each one just opened or closed — which endings are still reachable, which iconic weapons are now unobtainable, which romances your body type and voice actually allow, and which quests are about to expire.

It is not a walkthrough and it will not play the game for you. It answers the question walkthroughs are bad at: given everything I have already done, what have I lost and what is still on the table?

OPENING THE FILE

One self-contained HTML file. No install, no server, no account, and no network use whatsoever — the styling and fonts are inside the file, so it renders identically offline, from a USB stick, or in airplane mode.

On a computer

Save the file somewhere you will find it again, then double-click it, or drag it onto any open browser tab. Bookmark it once it opens so you are not hunting for it mid-session.

On iPhone or iPad — read this before you try

Tapping the file in the Files app will not work, and this is worth understanding rather than fighting. Files opens HTML in Apple's Quick Look preview, which disables JavaScript for security. There is no setting to turn it back on. Mobile Safari also cannot open a local file:// path. So on iPhone the app needs a real web address.

Symptoms of hitting this: a black screen, or the page appearing as plain unstyled text. Both mean scripts are not running, not that the file is damaged.

Two ways round it:

  • • Host it once. Drag the file onto app.netlify.com/drop or push it to GitHub Pages. Open the resulting link in Safari and choose Share → Add to Home Screen. It then launches like an installed app, and Safari caches it so it keeps working without signal.
  • • Use a file manager with a real browser. Apps such as Documents by Readdle run local HTML properly, JavaScript included.

On Android

Simpler than iOS. Open the file from Files or Downloads and pick Chrome when asked which app to use — Chrome runs local files with scripts enabled. Avoid any "preview" option, which has the same limitation as iOS. Chrome's Add to Home screen then gives you an app-like launcher.

Where your run is stored

Automatically, in this browser on this device — nowhere else. The QA Panel reports the storage mode it is using. If it reads MEMORY, the browser has blocked persistent storage and your run will vanish on refresh, so copy or export the JSON before closing the tab. Note that each browser and each device keeps its own separate run; they do not sync on their own.

MAKING IT FULLY OFFLINE

All layout, colour and logic are already inside this file — it works with no network. The two display typefaces are the single exception: they load from Google Fonts on first open, and without them the app falls back to the sharpest technical faces your device already has. It stays perfectly usable, just less distinctive.

To remove that last dependency, run this once on a desktop browser while online — it needs JavaScript, so it cannot be done from an iOS preview. It downloads the fonts, embeds them into a copy of this file, and strips the links. Host or transfer that copy and the type is correct everywhere, with no network at all.

Adds roughly 60–90 KB. Your current run is untouched — this only produces a new file.

MOVING A RUN BETWEEN DEVICES

Runs do not sync by themselves — there is no server involved. You move them by hand, which takes about ten seconds:

  • • Copy JSON shows your entire run as plain readable text. Copy it, then send it to your other device however you like — a note app, a message to yourself, anything.
  • • Paste JSON on the other device loads it. It replaces whatever run is open there, so copy that one first if you want to keep it.
  • • Export file and Import file do the same thing as a downloadable .json — better for cloud storage or long-term backups.

The format is deliberately plain JSON rather than an encoded blob, so you can open a saved run in any text editor and read exactly what happened. Worth exporting before a big rewind.

CHOICES ARE ONE-SHOT — USE REWIND

Once taken, a choice cannot be re-clicked. That is deliberate: re-taking one would re-apply its effects and quietly corrupt your totals.

To change something, use the ↺ rewind control on any past card. Rewinding discards everything after that point and recalculates the entire run from scratch — so flags, romances, world state and the arsenal all snap back to exactly what they were. There is no stale leftover state. Rewinding is safe; it is the intended way to explore.

READING THE TELEMETRY PANEL

  • • Johnny affinity — shown for interest only. It does not gate the secret ending, despite what many guides claim. The Reaper route depends solely on two specific choices.
  • • Romance — four tracked arcs, each 0 to 4. Ones your body type and voice make impossible are marked LOCKED with the reason. Note that the questlines are almost always still completable; only the romance itself is gated.
  • • Ending availability — OPEN means still reachable right now. It updates on every choice, so you can watch a route close in real time. Temperance is a final sub-choice inside Star, Sun or Reaper rather than a route of its own. Taking the Phantom Liberty cure marks every base ending LOCKED — Tower path taken.
  • • Two-gate flags — the Reaper needs reaperDialogue from the Chippin' In oil-fields conversation and reaperWait from the rooftop wait. Either alone does nothing.
  • • On a narrow screen the panel is collapsed by default. The summary line shows affinity, arc counts and how many endings remain open; tap Show for the rest.

THE ARSENAL AUDIT

Every tracked iconic sits in one of six states, and the distinctions among the last four are the whole point of the tool:

  • • ACQUIRED — you took it.
  • • PENDING — still ahead of you, still gettable.
  • • RECOVERABLE — you walked past it, and Herold Lowe at the EBM Petrochem Stadium black market in Dogtown is confirmed to restock it. Needs Phantom Liberty.
  • • RECOVERY_UNVERIFIED — you walked past it and Herold might restock it, but his stock for this item is unconfirmed across patches. Treat it as lost until you see it on his shelf: a false safety net costs you the item, while pessimism only costs a trip to Dogtown.
  • • CHOICE_LOCKED — gone because of a decision, not an oversight. Herold will never stock these. Chaos is the clearest case: spare Royce at The Pickup and it is gone for the run, no matter what you do later.
  • • MISSED_PERMANENT — walked past, and nothing can restock it. Usually a run without Phantom Liberty.

Before the point of no return, a pre-flight manifest lists exactly which items and arcs are about to be lost. Nothing commits until you confirm it.

  • • Ghost Wall — the 30-slot H10 stash wall as six-state sockets: acquired, live (still ahead and provably reachable), recoverable (Herold confirmed), unverified recovery, unreachable (proven lost — tap it to see the node that closed it, for next run), and undetermined (the solver could not settle it, or the item lives outside the decision graph). Undetermined is not failure. It is the tool refusing to guess.
